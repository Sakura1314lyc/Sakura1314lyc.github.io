二分答案是二分搜索的进阶应用，常用于解决 **最值问题（最大/最小）**。  

与普通二分搜索不同，它**不是在数组中找元素**，而是在**答案空间中寻找最优解**。

<!-- more -->

---

## 一、什么是二分答案？

二分答案的核心思想是：

> **对答案进行二分，而不是对数据进行二分**

---

### 📌 典型特征

当题目满足以下条件时，可以考虑使用二分答案：

- 求 **最小值最大化 / 最大值最小化**
- 问 **是否可以做到某件事**
- 存在“至少 / 至多 / 不超过”等限制
- **答案具有单调性**

---

### 🧠 举个例子

> 给一个数组，把它分成 k 段，使得每段的和的最大值最小

👉 你要找的不是位置，而是一个“答案值”

---

## 二、核心模板

```cpp
bool check(int mid) {
    // 判断当答案为 mid 时，是否满足条件
}

int solve() {
    int left = 最小可能答案;
    int right = 最大可能答案;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (check(mid)) {
            right = mid;      // 找最小可行解
        } else {
            left = mid + 1;
        }
    }

    return left;
}

```
## 三、三步搞定二分答案

### 1️⃣ 确定答案范围

问自己：

- 最小可能是多少？
- 最大可能是多少？

---

### 2️⃣ 设计 check 函数（最关键🔥）

👉 check 的本质：

> **把题目条件翻译成“是否成立”**

---

### 3️⃣ 判断单调性

必须满足：

答案越大 → 越容易满足（或相反）

---
---

## 四、二分答案 vs 二分搜索

| 类型 | 二分搜索 | 二分答案 |
|------|--------|---------|
| 查什么 | 数组中的值 | 最优解 |
| 数据要求 | 有序数组 | 单调性 |
| 判断方式 | nums[mid] | check(mid) |
| 本质 | 找元素 | 猜答案 |

---

## 五、常见错误（高频踩坑⚠️）

### ❌ 1. 没有单调性

👉 二分直接失效

---

### ❌ 2. check 写错

👉 最常见错误！

---

### ❌ 3. 边界写错

记住：

- 求最小 → `right = mid`
- 求最大 → `left = mid`

---

## 六、一句话总结

> **二分搜索是在数组里找数，二分答案是在答案里找答案**

## 🔚 总结

二分答案的本质是：

1. 构造答案区间  
2. 利用单调性  
3. 通过 check 函数不断缩小范围  

掌握之后，你会发现很多“最值问题”都可以用二分轻松解决 🚀
