# 一、排序算法总览

| 排序算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
| --- | --- | --- | --- | --- |
| 冒泡排序 | O(n^2) | O(n^2) | O(1) | 稳定 |
| 选择排序 | O(n^2) | O(n^2) | O(1) | 不稳定 |
| 插入排序 | O(n^2) | O(n^2) | O(1) | 稳定 |
| 希尔排序 | 约 O(n^1.3 ~ n^2) | O(n^2) | O(1) | 不稳定 |
| 归并排序 | O(nlogn) | O(nlogn) | O(n) | 稳定 |
| 快速排序 | O(nlogn) | O(n^2) | O(logn) | 不稳定 |
| 堆排序 | O(nlogn) | O(nlogn) | O(1) | 不稳定 |
| 计数排序 | O(n + k) | O(n + k) | O(k) | 稳定 |
| 桶排序 | 视分布而定 | 最坏 O(n^2) | O(n + k) | 取决于桶内排序 |
| 基数排序 | O(d(n + k)) | O(d(n + k)) | O(n + k) | 稳定 |

其中：

- `n` 是元素个数
- `k` 是值域大小
- `d` 是位数

# 二、冒泡排序

## 1. 思想

反复比较相邻两个元素，如果顺序错误就交换。  
每一轮都能把当前未排序部分中的最大值“冒泡”到最后面。

## 2. 特点

- 时间复杂度：O(n^2)
- 空间复杂度：O(1)
- **稳定排序**
- 可以通过“是否发生交换”做一点优化

## 3. 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void bubbleSort(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (nums[j] > nums[j + 1]) {
                swap(nums[j], nums[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

## 4. 例题：[LeetCode 912. 排序数组](https://leetcode.cn/problems/sort-an-array/)

**题目描述**：给你一个整数数组 nums，请你将该数组升序排列。

**示例**：
输入：nums = [5,2,3,1]
输出：[1,2,3,5]

**解题思路**：直接使用冒泡排序对数组进行排序即可。

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        bubbleSort(nums);
        return nums;
    }
private:
    void bubbleSort(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n - 1; i++) {
            bool swapped = false;
            for (int j = 0; j < n - i - 1; j++) {
                if (nums[j] > nums[j + 1]) {
                    swap(nums[j], nums[j + 1]);
                    swapped = true;
                }
            }
            if (!swapped) break;
        }
    }
};
```

# 三、选择排序

## 1. 思想

每一轮从未排序部分中选出最小值，放到当前应该放的位置。

## 2. 特点

- 时间复杂度：O(n^2)
- 空间复杂度：O(1)
- **不稳定排序**
- 无论数组是否接近有序，性能都差不多

## 3. 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void selectionSort(vector<int>& nums) {
    int n = nums.size();
    for (int i = 0; i < n; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (nums[j] < nums[minIndex]) {
                minIndex = j;
            }
        }
        swap(nums[i], nums[minIndex]);
    }
}
```

## 4. 例题：[LeetCode 912. 排序数组](https://leetcode.cn/problems/sort-an-array/)

**题目描述**：给你一个整数数组 nums，请你将该数组升序排列。

**示例**：
输入：nums = [5,2,3,1]
输出：[1,2,3,5]

**解题思路**：使用选择排序，每次选择当前未排序部分的最小元素放到正确位置。

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        selectionSort(nums);
        return nums;
    }
private:
    void selectionSort(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            int minIndex = i;
            for (int j = i + 1; j < n; j++) {
                if (nums[j] < nums[minIndex]) {
                    minIndex = j;
                }
            }
            swap(nums[i], nums[minIndex]);
        }
    }
};
```
# 四、插入排序

## 1. 思想

把数组分成“已排序部分”和“未排序部分”，每次从未排序部分取出一个元素，插入到已排序部分中的合适位置。

## 2. 特点

- 时间复杂度：O(n^2)
- 空间复杂度：O(1)
- **稳定排序**
- 对“近乎有序”的数组表现较好

## 3. 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void insertionSort(vector<int>& nums) {
    int n = nums.size();
    for (int i = 1; i < n; i++) {
        int key = nums[i];
        int j = i - 1;
        while (j >= 0 && nums[j] > key) {
            nums[j + 1] = nums[j];
            j--;
        }
        nums[j + 1] = key;
    }
}
```

## 4. 补充

相比“交换式插入”，这种“先保存 key，再整体后移”的写法更标准，也更高效一点。

## 5. 例题：[LeetCode 147. 对链表进行插入排序](https://leetcode.cn/problems/insertion-sort-list/)

**题目描述**：对链表进行插入排序。

**示例**：
输入：head = [4,2,1,3]
输出：[1,2,3,4]

**解题思路**：使用插入排序的思想，对链表进行排序。维护一个已排序的链表，每次将当前节点插入到正确位置。

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* insertionSortList(ListNode* head) {
        if (!head || !head->next) return head;
        
        ListNode* dummy = new ListNode(0);
        ListNode* curr = head;
        
        while (curr) {
            ListNode* prev = dummy;
            while (prev->next && prev->next->val < curr->val) {
                prev = prev->next;
            }
            ListNode* next = curr->next;
            curr->next = prev->next;
            prev->next = curr;
            curr = next;
        }
        
        return dummy->next;
    }
};
```

# 五、希尔排序

## 1. 思想

希尔排序本质上是插入排序的改进版。
它先按较大的间隔 gap 分组进行插入排序，逐步缩小 gap，最后 gap = 1时完成整体排序。

## 2. 特点

- 是插入排序的升级版
- 时间复杂度与增量序列有关
- **不稳定排序**
- 通常比普通 O(n^2) 排序快

## 3. 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void shellSort(vector<int>& nums) {
    int n = nums.size();
    int gap = 1;
    while (gap < n / 3) {
        gap = gap * 3 + 1;
    }

    while (gap >= 1) {
        for (int i = gap; i < n; i++) {
            int temp = nums[i];
            int j = i;
            while (j >= gap && nums[j - gap] > temp) {
                nums[j] = nums[j - gap];
                j -= gap;
            }
            nums[j] = temp;
        }
        gap /= 3;
    }
}
```

## 4. 例题：[LeetCode 912. 排序数组](https://leetcode.cn/problems/sort-an-array/)

**题目描述**：给你一个整数数组 nums，请你将该数组升序排列。

**示例**：
输入：nums = [5,2,3,1]
输出：[1,2,3,5]

**解题思路**：使用希尔排序对数组进行排序，通过逐步减小间隔来提高效率。

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        shellSort(nums);
        return nums;
    }
private:
    void shellSort(vector<int>& nums) {
        int n = nums.size();
        int gap = 1;
        while (gap < n / 3) {
            gap = gap * 3 + 1;
        }

        while (gap >= 1) {
            for (int i = gap; i < n; i++) {
                int temp = nums[i];
                int j = i;
                while (j >= gap && nums[j - gap] > temp) {
                    nums[j] = nums[j - gap];
                    j -= gap;
                }
                nums[j] = temp;
            }
            gap /= 3;
        }
    }
};
```

# 六、归并排序

## 1. 思想

归并排序使用 分治思想：
1. 先把数组分成左右两半
2. 分别排序
3. 再把两个有序数组合并起来

## 2. 特点
- 时间复杂度：O(nlogn)
- 空间复杂度：O(n)
- **稳定排序**
- 非常适合链表排序、外部排序、逆序对问题

## 3. 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void merge(vector<int>& nums, int left, int mid, int right) {
    vector<int> temp;
    int i = left, j = mid + 1;

    while (i <= mid && j <= right) {
        if (nums[i] <= nums[j]) temp.push_back(nums[i++]);
        else temp.push_back(nums[j++]);
    }

    while (i <= mid) temp.push_back(nums[i++]);
    while (j <= right) temp.push_back(nums[j++]);

    for (int k = 0; k < (int)temp.size(); k++) {
        nums[left + k] = temp[k];
    }
}

void mergeSort(vector<int>& nums, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(nums, left, mid);
    mergeSort(nums, mid + 1, right);
    merge(nums, left, mid, right);
}
```

## 4. 例题：[LeetCode 148. 排序链表](https://leetcode.cn/problems/sort-list/)

**题目描述**：给你链表的头结点 head，请将其按升序排列并返回排序后的链表。

**示例**：
输入：head = [4,2,1,3]
输出：[1,2,3,4]

**解题思路**：使用归并排序的思想，对链表进行排序。先找到中点，将链表分成两半，递归排序后再合并。

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;
        
        // 找到中点
        ListNode* slow = head;
        ListNode* fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        ListNode* mid = slow->next;
        slow->next = nullptr;
        
        // 递归排序左右两半
        ListNode* left = sortList(head);
        ListNode* right = sortList(mid);
        
        // 合并两个有序链表
        return merge(left, right);
    }
    
private:
    ListNode* merge(ListNode* l1, ListNode* l2) {
        ListNode* dummy = new ListNode(0);
        ListNode* curr = dummy;
        
        while (l1 && l2) {
            if (l1->val < l2->val) {
                curr->next = l1;
                l1 = l1->next;
            } else {
                curr->next = l2;
                l2 = l2->next;
            }
            curr = curr->next;
        }
        
        curr->next = l1 ? l1 : l2;
        return dummy->next;
    }
};
```

# 七、快速排序

## 1. 思想
快速排序的核心是 partition（划分）：
- 选一个基准值 pivot
- 把小于等于它的放左边
- 把大于等于它的放右边
- 然后递归处理左右区间
## 2. 特点
- 平均时间复杂度：O(nlogn)
- 最坏时间复杂度：O(n^2)
- **不稳定排序**
- 实际中通常很快，是非常经典的高性能排序

## 3. 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

int partition(vector<int>& nums, int left, int right) {
    int pivot = nums[right];
    int i = left - 1;

    for (int j = left; j < right; j++) {
        if (nums[j] <= pivot) {
            i++;
            swap(nums[i], nums[j]);
        }
    }
    swap(nums[i + 1], nums[right]);
    return i + 1;
}

void quickSort(vector<int>& nums, int left, int right) {
    if (left >= right) return;
    int p = partition(nums, left, right);
    quickSort(nums, left, p - 1);
    quickSort(nums, p + 1, right);
}
```

## 4. 例题：[LeetCode 215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

**题目描述**：给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。请注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。

**示例**：
输入：nums = [3,2,1,5,6,4], k = 2
输出：5

**解题思路**：使用快速排序的思想，通过 partition 函数找到第 k 大的元素，避免完全排序。

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        int n = nums.size();
        int left = 0, right = n - 1;
        while (true) {
            int pivotIndex = partition(nums, left, right);
            if (pivotIndex == n - k) {
                return nums[pivotIndex];
            } else if (pivotIndex < n - k) {
                left = pivotIndex + 1;
            } else {
                right = pivotIndex - 1;
            }
        }
    }
    
private:
    int partition(vector<int>& nums, int left, int right) {
        int pivot = nums[right];
        int i = left - 1;
        for (int j = left; j < right; j++) {
            if (nums[j] >= pivot) {  // 注意这里是 >= 因为要找第k大
                i++;
                swap(nums[i], nums[j]);
            }
        }
        swap(nums[i + 1], nums[right]);
        return i + 1;
    }
};
```

# 八、堆排序

## 1. 思想
堆排序的核心分两步：
1. 先把数组建成一个大顶堆
2. 反复把堆顶元素放到数组末尾，再调整堆


## 2. 特点
- 时间复杂度：O(nlogn)
- 空间复杂度：O(1)
- **不稳定排序**
- 适合需要原地排序、且想保证最坏复杂度时使用

## 3. 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

void heapify(vector<int>& nums, int n, int i) {
    int largest = i;
    int l = 2 * i + 1;
    int r = 2 * i + 2;

    if (l < n && nums[l] > nums[largest]) {
        largest = l;
    }
    if (r < n && nums[r] > nums[largest]) {
        largest = r;
    }

    if (largest != i) {
        swap(nums[i], nums[largest]);
        heapify(nums, n, largest);
    }
}

void heapSort(vector<int>& nums) {
    int n = nums.size();

    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(nums, n, i);
    }

    for (int i = n - 1; i > 0; i--) {
        swap(nums[0], nums[i]);
        heapify(nums, i, 0);
    }
}
```

## 4. 例题：[LeetCode 215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

**题目描述**：给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

**示例**：
输入：nums = [3,2,1,5,6,4], k = 2
输出：5

**解题思路**：使用堆排序的思想，维护一个大小为 k 的小顶堆，堆顶即为第 k 大的元素。

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        priority_queue<int, vector<int>, greater<int>> pq;
        for (int num : nums) {
            pq.push(num);
            if (pq.size() > k) {
                pq.pop();
            }
        }
        return pq.top();
    }
};
```

# 九、计数排序

## 1. 思想

计数排序不是基于比较的排序。
它统计每个数出现的次数，再根据计数结果还原出有序数组。


## 2. 特点
- 时间复杂度：O(n + k)
- 空间复杂度：O(k)
- **稳定排序**
- 要求值域不能太大

## 3. 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void countingSort(vector<int>& nums) {
    if (nums.empty()) return;

    int minVal = *min_element(nums.begin(), nums.end());
    int maxVal = *max_element(nums.begin(), nums.end());

    int offset = -minVal;
    vector<int> count(maxVal - minVal + 1, 0);

    for (int x : nums) {
        count[x + offset]++;
    }

    for (int i = 1; i < (int)count.size(); i++) {
        count[i] += count[i - 1];
    }

    vector<int> sorted(nums.size());
    for (int i = nums.size() - 1; i >= 0; i--) {
        sorted[count[nums[i] + offset] - 1] = nums[i];
        count[nums[i] + offset]--;
    }

    nums = sorted;
}
```

## 4. 例题：[LeetCode 1122. 数组的相对排序](https://leetcode.cn/problems/relative-sort-array/)

**题目描述**：给你两个数组，arr1 和 arr2，arr2 中的元素各不相同，arr2 中的每个元素都出现在 arr1 中。对 arr1 中的元素进行排序，使 arr1 中项的相对顺序和 arr2 中的相对顺序相同。未在 arr2 中出现过的元素需要按照升序放在 arr1 的末尾。

**示例**：
输入：arr1 = [2,3,1,3,2,4,6,7,9,2,19], arr2 = [2,1,4,3,9,6]
输出：[2,2,2,1,4,3,3,9,6,7,19]

**解题思路**：使用计数排序的思想，先统计 arr1 中每个元素的出现次数，然后按照 arr2 的顺序输出，最后输出不在 arr2 中的元素。

```cpp
class Solution {
public:
    vector<int> relativeSortArray(vector<int>& arr1, vector<int>& arr2) {
        vector<int> count(1001, 0);
        for (int num : arr1) {
            count[num]++;
        }
        
        vector<int> result;
        for (int num : arr2) {
            while (count[num] > 0) {
                result.push_back(num);
                count[num]--;
            }
        }
        
        for (int i = 0; i <= 1000; i++) {
            while (count[i] > 0) {
                result.push_back(i);
                count[i]--;
            }
        }
        
        return result;
    }
};
```

# 十、桶排序

## 1. 思想

桶排序把元素映射到若干个桶中：
1. 分桶
2. 每个桶内部排序
3. 依次合并每个桶

## 2. 特点
- 当数据分布比较均匀时，效率很高
- 稳定性取决于桶内排序算法
- 实现上比前面几种更依赖“数据分布”

## 3. 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void bucketSort(vector<int>& nums) {
    if (nums.empty()) return;

    int minVal = *min_element(nums.begin(), nums.end());
    int maxVal = *max_element(nums.begin(), nums.end());

    int bucketSize = 10;
    int bucketCount = (maxVal - minVal) / bucketSize + 1;
    vector<vector<int>> buckets(bucketCount);

    for (int num : nums) {
        int index = (num - minVal) / bucketSize;
        buckets[index].push_back(num);
    }

    nums.clear();
    for (auto& bucket : buckets) {
        sort(bucket.begin(), bucket.end());
        for (int x : bucket) {
            nums.push_back(x);
        }
    }
}
```

## 4. 例题：[LeetCode 164. 最大间距](https://leetcode.cn/problems/maximum-gap/)

**题目描述**：给定一个无序的数组，找出数组在排序之后，相邻元素之间最大的差值。如果数组元素个数小于 2，则返回 0。

**示例**：
输入：nums = [3,6,9,1]
输出：3

**解题思路**：使用桶排序的思想，将元素分配到桶中，然后在相邻桶之间计算最大间距。

```cpp
class Solution {
public:
    int maximumGap(vector<int>& nums) {
        int n = nums.size();
        if (n < 2) return 0;
        
        int minVal = *min_element(nums.begin(), nums.end());
        int maxVal = *max_element(nums.begin(), nums.end());
        
        int bucketSize = max(1, (maxVal - minVal) / (n - 1));
        int bucketCount = (maxVal - minVal) / bucketSize + 1;
        
        vector<int> bucketMin(bucketCount, INT_MAX);
        vector<int> bucketMax(bucketCount, INT_MIN);
        
        for (int num : nums) {
            int index = (num - minVal) / bucketSize;
            bucketMin[index] = min(bucketMin[index], num);
            bucketMax[index] = max(bucketMax[index], num);
        }
        
        int maxGap = 0;
        int prevMax = minVal;
        for (int i = 0; i < bucketCount; i++) {
            if (bucketMin[i] == INT_MAX) continue;
            maxGap = max(maxGap, bucketMin[i] - prevMax);
            prevMax = bucketMax[i];
        }
        
        return maxGap;
    }
};
```
# 十一、基数排序

## 1. 思想

基数排序按“位数”来排序。
常见的是 LSD（从低位到高位）：
1. 先按个位排序
2. 再按十位排序
3. 再按百位排序
4. ……
由于每一轮使用的是 稳定排序，最终整体有序

## 2. 特点
- 时间复杂度：O(d(n + k))
- 空间复杂度：O(n + k)
- **稳定排序**
- 很适合非负整数、位数有限的数据

## 3. 代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void countSortByDigit(vector<int>& nums, int exp) {
    vector<int> output(nums.size());
    vector<int> count(10, 0);

    for (int num : nums) {
        int digit = (num / exp) % 10;
        count[digit]++;
    }

    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }

    for (int i = nums.size() - 1; i >= 0; i--) {
        int digit = (nums[i] / exp) % 10;
        output[count[digit] - 1] = nums[i];
        count[digit]--;
    }

    nums = output;
}

void radixSort(vector<int>& nums) {
    if (nums.empty()) return;

    int minVal = *min_element(nums.begin(), nums.end());
    if (minVal < 0) {
        for (int& x : nums) x -= minVal;
    }

    int maxVal = *max_element(nums.begin(), nums.end());
    for (int exp = 1; maxVal / exp > 0; exp *= 10) {
        countSortByDigit(nums, exp);
    }

    if (minVal < 0) {
        for (int& x : nums) x += minVal;
    }
}
```

## 4. 例题：[LeetCode 164. 最大间距](https://leetcode.cn/problems/maximum-gap/)

**题目描述**：给定一个无序的数组，找出数组在排序之后，相邻元素之间最大的差值。如果数组元素个数小于 2，则返回 0。

**示例**：
输入：nums = [3,6,9,1]
输出：3

**解题思路**：使用基数排序的思想，先对数组进行排序，然后计算相邻元素的差值。

```cpp
class Solution {
public:
    int maximumGap(vector<int>& nums) {
        int n = nums.size();
        if (n < 2) return 0;
        
        // 使用基数排序对数组排序
        radixSort(nums);
        
        int maxGap = 0;
        for (int i = 1; i < n; i++) {
            maxGap = max(maxGap, nums[i] - nums[i - 1]);
        }
        
        return maxGap;
    }
    
private:
    void countSortByDigit(vector<int>& nums, int exp) {
        vector<int> output(nums.size());
        vector<int> count(10, 0);

        for (int num : nums) {
            int digit = (num / exp) % 10;
            count[digit]++;
        }

        for (int i = 1; i < 10; i++) {
            count[i] += count[i - 1];
        }

        for (int i = nums.size() - 1; i >= 0; i--) {
            int digit = (nums[i] / exp) % 10;
            output[count[digit] - 1] = nums[i];
            count[digit]--;
        }

        nums = output;
    }

    void radixSort(vector<int>& nums) {
        if (nums.empty()) return;

        int maxVal = *max_element(nums.begin(), nums.end());
        for (int exp = 1; maxVal / exp > 0; exp *= 10) {
            countSortByDigit(nums, exp);
        }
    }
};
```

# 十二、怎么选排序算法

如果是刚入门，可以这样记：
## 1. 基础理解用

- 冒泡排序
- 选择排序
- 插入排序
这三种最适合帮助你建立排序的直觉。
## 2. 面试和刷题高频

- 快速排序
- 归并排序
- 堆排序
这三种最重要，必须熟。
## 3. 特殊场景专用

- 计数排序：值域小
- 桶排序：分布均匀
- 基数排序：按位排序
## 4. 工程上常见思维

- 小规模数据：插入排序常常很好用
- 追求平均速度：快速排序
- 追求稳定性：归并排序
- 追求原地且最坏稳定复杂度：堆排序

# 十三、总结

这篇文章从入门到进阶，系统整理了常见排序算法。
学习排序时，建议分三层掌握：
## 第一层：先会写基础排序
- 冒泡
- 选择
- 插入
## 第二层：掌握高频核心排序
- 归并
- 快速
- 堆
## 第三层：理解非比较排序
- 计数
- 桶
- 基数
真正刷题时，不只是“会背模板”，更重要的是知道：
1. 什么时候该用哪种排序
2. 稳定性会不会影响结果
3. 数据范围是否适合特殊排序
4. 能否把排序思想迁移到别的问题
