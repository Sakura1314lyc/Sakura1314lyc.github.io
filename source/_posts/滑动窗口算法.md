滑动窗口可以归为 **快慢双指针算法**。  
使用一快一慢两个指针前后相随，中间的部分就是一个“窗口”。

滑动窗口算法技巧主要用来解决 **子数组或子串问题**，例如：

- 寻找符合某个条件的 **最长子数组**
- 寻找符合某个条件的 **最短子数组**
- 统计满足条件的子串数量

---

# 一、滑动窗口的基本思想

滑动窗口算法的核心思想是：

> 维护一个窗口，不断向右滑动，并在过程中更新答案。

基本逻辑如下：

```cpp
// 索引区间 [left, right) 是窗口
int left = 0, right = 0;

while (right < nums.size()) {
    // 增大窗口
    window.addLast(nums[right]);
    right++;

    while (needShrink) {
        // 缩小窗口
        window.removeFirst(nums[left]);
        left++;
    }
}
```
# 二、 注意事项

滑动窗口并不能穷举所有子串
如果题目要求穷举所有子串，一般需要使用两层for循环

```cpp
for(int i = 0; i < n; i++){
    for(int j = i; j < n; j++){
        // 子串 [i, j]
    }
}

滑动窗口主要用于优化子串问题的时间复杂度
```

# 四、滑动窗口解题三问
以后遇到滑动窗口问题,可以先思考三个关键问题:
## 1 什么时候移动 right 扩大窗口？
当窗口需要继续包含新的元素时，就移动 right。
同时需要 更新窗口中的统计数据。
## 2 什么时候移动 left 缩小窗口？
当窗口不满足题目条件时，需要移动 left。
同时要 移除窗口中的元素并更新统计数据。
## 3 什么时候更新答案？
当窗口 满足题目条件 时，就可以更新答案，例如：
• 更新最长长度
• 更新最短长度
• 更新满足条件的次数

# 五、滑动窗口经典例题

## 例题 1：[LeetCode 3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

**题目描述**：给定一个字符串 s，请你找出其中不含有重复字符的最长子串的长度。

**示例**：
输入：s = "abcabcbb"
输出：3
解释：最长子串是 "abc"，长度为 3。

**解题思路**：维护一个窗口，记录窗口内字符出现次数。当出现重复字符时，左指针右移。

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_map<char, int> window;
        int left = 0, maxLen = 0;
        
        for (int right = 0; right < s.size(); right++) {
            window[s[right]]++;
            
            // 收缩窗口直到没有重复字符
            while (window[s[right]] > 1) {
                window[s[left]]--;
                left++;
            }
            
            maxLen = max(maxLen, right - left + 1);
        }
        
        return maxLen;
    }
};
```

**时间复杂度**：O(n)
**空间复杂度**：O(min(m, n))，其中 m 是字符集大小

## 例题 2：[LeetCode 76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)

**题目描述**：给你一个字符串 s、一个字符串 t，返回 s 中涵盖 t 所有字符的最小子串。如果 s 中不存在涵盖 t 所有字符的子串，则返回空字符串。

**示例**：
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"

**解题思路**：维护窗口中的字符计数，扩展右指针直到满足条件，然后收缩左指针找最小值。

```cpp
class Solution {
public:
    string minWindow(string s, string t) {
        if (t.size() > s.size()) return "";
        
        unordered_map<char, int> tCount, window;
        for (char c : t) tCount[c]++;
        
        int left = 0, formed = 0, required = tCount.size();
        int minLen = INT_MAX, minStart = 0;
        
        for (int right = 0; right < s.size(); right++) {
            char c = s[right];
            window[c]++;
            
            if (tCount.count(c) && window[c] == tCount[c]) {
                formed++;
            }
            
            while (left <= right && formed == required) {
                if (right - left + 1 < minLen) {
                    minLen = right - left + 1;
                    minStart = left;
                }
                
                char d = s[left];
                window[d]--;
                if (tCount.count(d) && window[d] < tCount[d]) {
                    formed--;
                }
                left++;
            }
        }
        
        return minLen == INT_MAX ? "" : s.substr(minStart, minLen);
    }
};
```

**时间复杂度**：O(|s| + |t|)
**空间复杂度**：O(|s| + |t|)

## 例题 3：[LeetCode 209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/)

**题目描述**：给定一个含有 n 个正整数的数组和一个正整数 target，找出该数组中满足其和 ≥ target 的长度最小的连续子数组，并返回其长度。

**示例**：
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是满足条件的长度最小的子数组。

**解题思路**：使用滑动窗口维护当前和，当和 ≥ target 时尝试收缩窗口。

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int left = 0, sum = 0, minLen = INT_MAX;
        
        for (int right = 0; right < nums.size(); right++) {
            sum += nums[right];
            
            while (sum >= target) {
                minLen = min(minLen, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }
        
        return minLen == INT_MAX ? 0 : minLen;
    }
};
```

**时间复杂度**：O(n)
**空间复杂度**：O(1)

## 例题 4：[LeetCode 567. 字符串的排列](https://leetcode.cn/problems/permutation-in-string/)

**题目描述**：给你两个字符串 s1 和 s2，写一个函数来判断 s2 是否包含 s1 的排列。

**示例**：
输入：s1 = "ab", s2 = "eidbaooo"
输出：true
解释：s2 包含 s1 的排列 "ba"。

**解题思路**：维护一个长度为 s1.size() 的滑动窗口，检查窗口内字符计数是否与 s1 相同。

```cpp
class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        if (s1.size() > s2.size()) return false;
        
        vector<int> s1Count(26, 0), window(26, 0);
        for (char c : s1) s1Count[c - 'a']++;
        
        int left = 0;
        for (int right = 0; right < s2.size(); right++) {
            window[s2[right] - 'a']++;
            
            if (right - left + 1 > s1.size()) {
                window[s2[left] - 'a']--;
                left++;
            }
            
            if (window == s1Count) return true;
        }
        
        return false;
    }
};
```

**时间复杂度**：O(n)
**空间复杂度**：O(1)

## 总结

滑动窗口的精髓在于：

1. **何时扩展**：右指针不断向右移动，加入新元素
2. **何时收缩**：当窗口不满足条件时，左指针右移
3. **何时更新答案**：窗口满足条件时立即更新

掌握这三点，大部分子串/子数组问题都能高效解决！
