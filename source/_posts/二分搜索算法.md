二分搜索通常用于解决 **单调函数问题**。  
二分思想的核心在于**快速收缩搜索区间**
如果函数 `f(x)` 随着 `x` 单调变化，就可以使用二分搜索寻找满足条件的 `x`。

## 一、二分搜索通用模板

```cpp
// 函数 f 是关于自变量 x 的单调函数
int f(int x) {
    // ...
}

// 主函数，在 f(x) == target 的约束下求 x 的最值
int solution(vector<int>& nums, int target) {
    if (nums.size() == 0) return -1;

    // 问自己：自变量 x 的最小值是多少？
    int left = ...;

    // 问自己：自变量 x 的最大值是多少？
    int right = ... + 1;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (f(mid) == target) {
            // 问自己：题目是求左边界还是右边界？
            // ...
        } 
        else if (f(mid) < target) {
            // 问自己：怎么让 f(x) 大一点？
            // ...
        } 
        else if (f(mid) > target) {
            // 问自己：怎么让 f(x) 小一点？
            // ...
        }
    }

    return left;
}
```

## 二、二分搜索三步骤

使用二分搜索时，可以按照下面三个步骤思考：

### 1. 确定 `x`、`f(x)` 和 `target`

- `x`：自变量（需要搜索的值）
- `f(x)`：根据 `x` 计算得到的函数值
- `target`：目标值

---

### 2. 确定搜索区间

找到 `x` 的 **最小值和最大值**，作为二分搜索的区间：

```cpp
int left = 最小值;
int right = 最大值 + 1;
```

---

### 3. 选择边界类型

根据题目需求选择：

- **左边界二分**
- **右边界二分**

不同边界更新 `left` 和 `right` 的方式不同。

---

## 三、重要注意事项

在使用二分搜索时，一定要判断 **函数的单调性**。

- 如果 `f(x)` **单调递增**：正常使用模板
- 如果 `f(x)` **单调递减**：需要把判断条件 **反过来**

否则会导致搜索方向错误。

---
## 四、时间复杂度

时间复杂度：`O(log n)`  
空间复杂度：`O(1)`


## 五、总结

二分搜索的核心是：

1. 找到单调函数 `f(x)`
2. 确定 `x` 的搜索区间
3. 根据题目需求选择左边界或右边界
4. 判断函数是递增还是递减

## 六、经典例题

### 例题 1：[LeetCode 704. 二分查找](https://leetcode.cn/problems/binary-search/)

**题目描述**：给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target，写一个函数搜索 nums 中的 target，如果目标值存在返回下标，否则返回 -1。

**示例**：
输入：nums = [-1,0,3,1,4,5,9,9,9], target = 9
输出：4

**解题思路**：直接应用二分搜索模板。

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0, right = nums.size();
        
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        
        return -1;
    }
};
```

**时间复杂度**：O(log n)
**空间复杂度**：O(1)

### 例题 2：[LeetCode 34. 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

**题目描述**：给定一个按照升序排列的整数数组 nums，和一个目标值 target。找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值 target，返回 [-1, -1]。

**示例**：
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]

**解题思路**：分别做两次二分查找，一次找左边界，一次找右边界。

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        if (nums.empty()) return {-1, -1};
        
        int left = findFirst(nums, target);
        if (left == -1) return {-1, -1};
        
        int right = findLast(nums, target);
        return {left, right};
    }
    
private:
    int findFirst(vector<int>& nums, int target) {
        int left = 0, right = nums.size();
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left < nums.size() && nums[left] == target ? left : -1;
    }
    
    int findLast(vector<int>& nums, int target) {
        int left = 0, right = nums.size();
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] <= target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left - 1;
    }
};
```

**时间复杂度**：O(log n)
**空间复杂度**：O(1)

### 例题 3：[LeetCode 33. 搜索旋转排序数组](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

**题目描述**：整数数组 nums 按升序排列，数组中存在一个旋转点。给你旋转后的数组 nums 和一个整数 target，如果 nums 中存在这个目标值 target，返回它的下标，否则返回 -1。

**示例**：
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4

**解题思路**：二分处理时需要判断 mid 在哪一段有序区间内，然后决定左右移动。

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0, right = nums.size() - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) return mid;
            
            // 左段有序
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }
            // 右段有序
            else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        
        return -1;
    }
};
```

**时间复杂度**：O(log n)
**空间复杂度**：O(1)
