提到树状数组（Fenwick Tree / BIT），大部分人第一时间想到的是 **单点修改 + 区间求和**。  
但其实树状数组经过简单的变形，也能轻松解决 **区间修改 + 单点查询** 的问题。

本篇是这个系列的第一篇——只用 **一个树状数组 + 差分思想** 来实现区间修改、单点查询。

---

# 一、问题模型

给定一个长度为 $n$ 的数组 $a$，支持两种操作：

1. **区间修改**：将 $[l, r]$ 内的每个数加上 $x$
2. **单点查询**：查询 $a[i]$ 的值

如果使用暴力，区间修改是 $O(n)$，查询是 $O(1)$，在数据量大时显然不行。  
如果使用线段树，固然可以，但杀鸡用牛刀——树状数组足以胜任。

---

# 二、核心思想：差分

设原数组为 $a[1..n]$，我们构造它的 **差分数组** $d$：

$$
d[i] = a[i] - a[i-1] \quad (a[0] = 0)
$$

那么原数组 $a[i]$ 其实就是差分数组的前缀和：

$$
a[i] = \sum_{k=1}^{i} d[k]
$$

**区间修改** $[l, r]$ 加上 $x$，反映在差分数组上只有 **两个位置** 发生变化：

$$
d[l] \mathrel{+}= x \qquad d[r+1] \mathrel{-}= x
$$

因为区间内部相邻元素的差值没有变，只有区间边界处的差值变了。

于是我们只需要维护差分数组 $d$，支持：

- **单点修改**（在 $d[l]$ 和 $d[r+1]$ 上加减）
- **前缀和查询**（求 $\sum_{k=1}^{i} d[k]$ 得到 $a[i]$）

这正是树状数组最擅长的领域。

---

# 三、算法流程

| 操作 | 实现方式 |
|------|----------|
| `add(l, x); add(r+1, -x)` | 在差分数组上做两次单点修改 |
| 查询 `a[i]` | `query(i)` 求差分前缀和 |

{% note info %}
**总结**：区间修改 + 单点查询 = 差分数组 + 树状数组（单点修改 + 区间查询）
{% endnote %}

# 四、代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500010;

int n, m;
long long tr[N];   // 树状数组维护差分数组

int lowbit(int x) {
    return x & -x;
}

void add(int x, long long k) {
    while (x <= n) {
        tr[x] += k;
        x += lowbit(x);
    }
}

long long query(int x) {
    long long res = 0;
    while (x > 0) {
        res += tr[x];
        x -= lowbit(x);
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    long long last = 0;
    for (int i = 1; i <= n; i++) {
        long long cur;
        cin >> cur;
        // 建树：差分值 d[i] = a[i] - a[i-1]
        add(i, cur - last);
        last = cur;
    }

    while (m--) {
        int op;
        cin >> op;
        if (op == 1) {
            int l, r;
            long long x;
            cin >> l >> r >> x;
            add(l, x);
            add(r + 1, -x);
        } else {
            int i;
            cin >> i;
            cout << query(i) << '\n';
        }
    }

    return 0;
}
```

**时间复杂度**：$O((n + m) \log n)$  
**空间复杂度**：$O(n)$

# 六、小结

- 树状数组本身支持 **单点修改** 和 **前缀和查询**
- 引入 **差分数组** 后，将区间修改变为两次单点修改，将单点查询变为前缀和查询
- 本质上是 **问题模型的转换**
