# 中国剩余定理详解

## 一、绪论

中国剩余定理（Chinese Remainder Theorem，CRT）是数论中的经典工具，常用于求解一组同余方程的最小非负解。

它在算法竞赛、密码学、计算数学等场景中非常常见，适合用于：

- 求解多模同余方程组
- 合并多个余数约束
- 计算大范畴内的最小解

本文还会顺便介绍：

- 最大公约数 `gcd`
- 最小公倍数 `lcm`
- 扩展欧几里得算法
- 逆元计算

---

## 二、gcd 与 lcm

### 1. gcd（最大公约数）

`gcd(a, b)` 表示 `a` 和 `b` 的最大公约数。

最常用的求法是欧几里得算法：

```
gcd(a, b) = gcd(b, a % b)
```

当 `b==0` 时，`gcd(a,0)=a`。

### 2. lcm（最小公倍数）

`lcm(a, b)` 表示 `a` 和 `b` 的最小公倍数。

一个常见公式：

```
lcm(a, b) = a / gcd(a, b) * b
```

这个公式先除后乘可以避免直接计算 `a*b` 的溢出。

---

## 三、扩展欧几里得算法

扩展欧几里得算法不仅能求 `gcd(a, b)`，还能求出一组整数 `x` 和 `y`，使得：

```
a*x + b*y = gcd(a, b)
```

这组系数 `x` 和 `y` 被称为贝祖等式的解。

### 递归实现

```cpp
long long extgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = extgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}
```

### 逆元计算

当 `a` 与 `mod` 互质时，`a` 在模 `mod` 下存在逆元 `inv`，满足：

```
a * inv ≡ 1 (mod mod)
```

可以使用扩展欧几里得算法求逆元：

```cpp
long long modInverse(long long a, long long mod) {
    long long x, y;
    long long g = extgcd(a, mod, x, y);
    if (g != 1) return -1; // 不互质时不存在逆元
    x %= mod;
    if (x < 0) x += mod;
    return x;
}
```

## 四、中国剩余定理基本形式

当模 `m_i` 两两互质时，方程组：

```
x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
...
x ≡ ak (mod mk)
```

存在唯一解 `x`，且在模 `M = m1*m2*...*mk` 下唯一。

不过实际编程中，我们更常用“逐步合并”的思路，将两个同余方程合并为一个。

---

## 五、通用 CRT 算法

### 1. 两个同余方程的合并

考虑：

```
x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
```

令 `g = gcd(m1, m2)`，如果 `a1 % g != a2 % g`，则无解。

如果有解，则令：

```
 m1' = m1 / g
 m2' = m2 / g
```

可以写成：

```
 x = a1 + m1 * t
```

代入第二个方程：

```
a1 + m1 * t ≡ a2 (mod m2)
```

化简得到：

```
m1 * t ≡ a2 - a1 (mod m2)
```

两边同除以 `g` 后，变为：

```
m1' * t ≡ (a2 - a1) / g (mod m2')
```

此时 `m1'` 与 `m2'` 互质，可以求出 `t` 的解。

### 2. 合并后的模

最终合并后得到的新方程：

```
x ≡ a (mod lcm(m1, m2))
```

其中：

```
 lcm(m1, m2) = m1 / g * m2
```

## 六、代码实现

下面给出一个通用 CRT 的 C++ 实现，支持非互质模的情况。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll INF = 4e18;

ll gcdll(ll a, ll b) {
    return b == 0 ? a : gcdll(b, a % b);
}

ll extgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    ll x1, y1;
    ll g = extgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

ll modInverse(ll a, ll mod) {
    ll x, y;
    ll g = extgcd(a, mod, x, y);
    if (g != 1) return -1;
    x %= mod;
    if (x < 0) x += mod;
    return x;
}

// 返回 {x, lcm}，若无解则 {0, -1}
pair<ll, ll> chineseRemainder(ll a1, ll m1, ll a2, ll m2) {
    ll x, y;
    ll g = extgcd(m1, m2, x, y);
    ll diff = a2 - a1;
    if (diff % g != 0) return {0, -1};

    ll m2_g = m2 / g;
    ll t = (diff / g % m2_g) * (x % m2_g) % m2_g;
    if (t < 0) t += m2_g;

    ll mod = m1 / g * m2;
    ll res = (a1 + m1 * t) % mod;
    if (res < 0) res += mod;
    return {res, mod};
}

int main() {
    int n;
    cin >> n;
    vector<ll> a(n), m(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i] >> m[i];
    }

    ll curA = a[0];
    ll curM = m[0];
    for (int i = 1; i < n; i++) {
        auto [nextA, nextM] = chineseRemainder(curA, curM, a[i], m[i]);
        if (nextM == -1) {
            cout << "No solution\n";
            return 0;
        }
        curA = nextA;
        curM = nextM;
    }

    cout << curA << " " << curM << "\n";
    return 0;
}
```

### 代码说明

- `gcdll` 计算最大公约数
- `extgcd` 求解贝祖等式系数
- `modInverse` 计算逆元，仅在互质情况下有效
- `chineseRemainder` 合并两个同余方程，返回新的解和新的模

## 八、扩展思考

### 1. 逆元与模的互质性

只有在 `gcd(a, mod) == 1` 时，`a` 的模逆元才存在。

否则方程 `a*x ≡ 1 (mod mod)` 无解。

### 2. 非互质模的 CRT

当 `m1` 和 `m2` 不互质时，不一定无解。如果两个余数在 `gcd(m1,m2)` 下一致，则仍可合并，否则无解。

### 3. 复杂度分析

上述 CRT 合并算法每次合并两个同余式，时间复杂度为 `O(n * log M)`，其中 `M` 是模数的大小。通常 `extgcd` 的复杂度为 `O(log min(m1,m2))`。

## 九、总结

中国剩余定理是数论中非常实用的工具，重要结论包括：

- 互质模时解唯一，模为所有模的乘积
- 非互质模时需要判断余数一致性
- 扩展欧几里得可用于求逆元和合并方程
- `gcd`、`lcm`、`逆元` 都是构造 CRT 的基础
