二分搜索模板

发表于2026-03-12|更新于2026-03-12|算法学习
|浏览量:

二分搜索通常用于解决 单调函数问题。
如果函数 f(x) 随着 x 单调变化，就可以使用二分搜索寻找满足条件的 x。

一、二分搜索通用模板

二、二分搜索三步骤

使用二分搜索时，可以按照下面三个步骤思考：

1. 确定 x、f(x) 和 target

  • x：自变量（需要搜索的值）
  • f(x)：根据 x 计算得到的函数值
  • target：目标值

2. 确定搜索区间

找到 x 的 最小值和最大值，作为二分搜索的区间：

3. 选择边界类型

根据题目需求选择：

  • 左边界二分
  • 右边界二分

不同边界更新 left 和 right 的方式不同。

三、重要注意事项

在使用二分搜索时，一定要判断 函数的单调性。

  • 如果 f(x) 单调递增：正常使用模板
  • 如果 f(x) 单调递减：需要把判断条件 反过来

否则会导致搜索方向错误。

四、时间复杂度

时间复杂度：O(log n)
空间复杂度：O(1)

五、总结

二分搜索的核心是：

  1. 找到单调函数 f(x)
  2. 确定 x 的搜索区间
  3. 根据题目需求选择左边界或右边界
  4. 判断函数是递增还是递减
