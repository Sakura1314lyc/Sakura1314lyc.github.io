一、变量 = 值 + 类型

Go 语言的变量在底层由值和类型组成，但接口变量和非接口变量的结构完全不同。

1.1 非接口变量

非接口变量（如 int、string、结构体）在编译时类型就完全确定，运行时只携带值：

var x int = 42   // 编译时已知类型 int，运行时只是 42 这个值
