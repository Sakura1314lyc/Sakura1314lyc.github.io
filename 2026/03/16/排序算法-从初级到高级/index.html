排序算法-从入门到进阶

发表于2026-03-16|更新于2026-03-16|算法学习
|浏览量:

排序算法是算法学习中的基础内容，也是面试和刷题中非常高频的知识点。
这篇文章按照 从简单到进阶 的顺序，整理常见排序算法，包括：

  • 冒泡排序
  • 选择排序
  • 插入排序
  • 希尔排序
  • 归并排序
  • 快速排序
  • 堆排序
  • 计数排序
  • 桶排序
  • 基数排序

一、排序算法总览

排序算法 平均时间复杂度 最坏时间复杂度 空间复杂度 稳定性
冒泡排序 O(n^2) O(n^2) O(1) 稳定
选择排序 O(n^2) O(n^2) O(1) 不稳定
插入排序 O(n^2) O(n^2) O(1) 稳定
希尔排序 约 O(n^1.3 ~ n^2) O(n^2) O(1) 不稳定
归并排序 O(nlogn) O(nlogn) O(n) 稳定
快速排序 O(nlogn) O(n^2) O(logn) 不稳定
堆排序 O(nlogn) O(nlogn) O(1) 不稳定
计数排序 O(n + k) O(n + k) O(k) 稳定
桶排序 视分布而定 最坏 O(n^2) O(n + k) 取决于桶内排序
基数排序 O(d(n + k)) O(d(n + k)) O(n + k) 稳定

其中：

  • n 是元素个数
  • k 是值域大小
  • d 是位数

二、冒泡排序

1. 思想

反复比较相邻两个元素，如果顺序错误就交换。
每一轮都能把当前未排序部分中的最大值“冒泡”到最后面。

2. 特点

  • 时间复杂度：O(n^2)
  • 空间复杂度：O(1)
  • 稳定排序
  • 可以通过“是否发生交换”做一点优化

3. 代码

三、选择排序

1. 思想

每一轮从未排序部分中选出最小值，放到当前应该放的位置。

2. 特点

  • 时间复杂度：O(n^2)
  • 空间复杂度：O(1)
  • 不稳定排序
  • 无论数组是否接近有序，性能都差不多

3. 代码

四、插入排序

1. 思想

把数组分成“已排序部分”和“未排序部分”，每次从未排序部分取出一个元素，插入到已排序部分中的合适位置。

2. 特点

  • 时间复杂度：O(n^2)
  • 空间复杂度：O(1)
  • 稳定排序
  • 对“近乎有序”的数组表现较好

3. 代码

4. 补充

相比“交换式插入”，这种“先保存 key，再整体后移”的写法更标准，也更高效一点。

五、希尔排序

1. 思想

希尔排序本质上是插入排序的改进版。
它先按较大的间隔 gap 分组进行插入排序，逐步缩小 gap，最后 gap = 1时完成整体排序。

2. 特点

  • 是插入排序的升级版
  • 时间复杂度与增量序列有关
  • 不稳定排序
  • 通常比普通 O(n^2) 排序快

3. 代码

六、归并排序

1. 思想

归并排序使用 分治思想：

  1. 先把数组分成左右两半
  2. 分别排序
  3. 再把两个有序数组合并起来

2. 特点

  • 时间复杂度：O(nlogn)
  • 空间复杂度：O(n)
  • 稳定排序
  • 非常适合链表排序、外部排序、逆序对问题

3. 代码

七、快速排序

1. 思想

快速排序的核心是 partition（划分）：

  • 选一个基准值 pivot
  • 把小于等于它的放左边
  • 把大于等于它的放右边
  • 然后递归处理左右区间

2. 特点

  • 平均时间复杂度：O(nlogn)
  • 最坏时间复杂度：O(n^2)
  • 不稳定排序
  • 实际中通常很快，是非常经典的高性能排序

3. 代码

八、堆排序

1. 思想

堆排序的核心分两步：

  1. 先把数组建成一个大顶堆
  2. 反复把堆顶元素放到数组末尾，再调整堆

2. 特点

  • 时间复杂度：O(nlogn)
  • 空间复杂度：O(1)
  • 不稳定排序
  • 适合需要原地排序、且想保证最坏复杂度时使用

3. 代码

九、计数排序

1. 思想

计数排序不是基于比较的排序。
它统计每个数出现的次数，再根据计数结果还原出有序数组。

2. 特点

  • 时间复杂度：O(n + k)
  • 空间复杂度：O(k)
  • 稳定排序
  • 要求值域不能太大

3. 代码

十、桶排序

1. 思想

桶排序把元素映射到若干个桶中：

  1. 分桶
  2. 每个桶内部排序
  3. 依次合并每个桶

2. 特点

  • 当数据分布比较均匀时，效率很高
  • 稳定性取决于桶内排序算法
  • 实现上比前面几种更依赖“数据分布”

3. 代码

十一、基数排序

1. 思想

基数排序按“位数”来排序。
常见的是 LSD（从低位到高位）：

  1. 先按个位排序
  2. 再按十位排序
  3. 再按百位排序
  4. ……
    由于每一轮使用的是 稳定排序，最终整体有序

2. 特点

  • 时间复杂度：O(d(n + k))
  • 空间复杂度：O(n + k)
  • 稳定排序
  • 很适合非负整数、位数有限的数据

3. 代码

十二、怎么选排序算法

如果是刚入门，可以这样记：

1. 基础理解用

  • 冒泡排序
  • 选择排序
  • 插入排序
    这三种最适合帮助你建立排序的直觉。

2. 面试和刷题高频

  • 快速排序
  • 归并排序
  • 堆排序
    这三种最重要，必须熟。

3. 特殊场景专用

  • 计数排序：值域小
  • 桶排序：分布均匀
  • 基数排序：按位排序

4. 工程上常见思维

  • 小规模数据：插入排序常常很好用
  • 追求平均速度：快速排序
  • 追求稳定性：归并排序
  • 追求原地且最坏稳定复杂度：堆排序

十三、总结

这篇文章从入门到进阶，系统整理了常见排序算法。
学习排序时，建议分三层掌握：

第一层：先会写基础排序

  • 冒泡
  • 选择
  • 插入

第二层：掌握高频核心排序

  • 归并
  • 快速
  • 堆

第三层：理解非比较排序

  • 计数
  • 桶
  • 基数
    真正刷题时，不只是“会背模板”，更重要的是知道：
  1. 什么时候该用哪种排序
  2. 稳定性会不会影响结果
  3. 数据范围是否适合特殊排序
  4. 能否把排序思想迁移到别的问题
